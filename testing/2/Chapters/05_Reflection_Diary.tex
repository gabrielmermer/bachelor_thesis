\section{Sticky moments analysis}
Analysis of the meaning of the sticky moments noted in the chapter 3


\begin{enumerate}
    \item \textbf{Missing image on the fishing store}
    
    The fishing store location seems to be missing a background image. It appears as just a pure black box.

    \item \textbf{Stair naming}
    
    Just like in the last test, the naming convention for the stairs was not intuitive, making the player confuse stairs going up with stairs going down.


    \item \textbf{Game loop broken}
    
    This includes two sticky moments that stem from the same source. The main bug is that the player can't activate the action to pick up his brother after stabilising his leg. That action should trigger the main entrance collapsing, forcing the player to find another exit out of the game, but since the first action couldn't be triggered the second one also didn't come off. 


    \item \textbf{Interaction need}
    
    The player expressed that they would like to have more interaction with the given game world. He said that he would like to be able to do more with the items that he collects. 



    \item \textbf{Item pickup impossible}
    
    It seems like the leg stabiliser can't be picked up. Upon log inspection it turned out that it was due to termporary voice recognition pipeline failure.


    \item \textbf{Infinite pistols}
    
    Due to a bug in the game logic the player could pick up infinite ammount of pistols form the gun store location. This led to him picking up 4 of them before moving on.


    \item \textbf{Double teleporation}
    
    At some point the voice control system malfunctioned and instead of moving from the Gun store to the Korean Snack Store it moved the player straight to the Lounge, which shoulnd't be possible. This bug was unable to be reproduced later and hasn't showed up and with any subsequent testing participants.

\end{enumerate}
