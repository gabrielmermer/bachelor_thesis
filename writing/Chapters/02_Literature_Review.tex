\subsection{UX}


\textcite{ibmWhatUserExperience2025} classifies User Experience as a holistic term that encompasses the whole interaction of the user with a given product, service, company or place. It's a sum of individual moments, feelings, thoughts, emotions and actions that take place during the interaction.

In this thesis, UX is important since immersion is deeply linked to the experience that the user has. 
It's very difficult to talk about the immersiveness of an experience without mentioning UX, since 
They are so deeply connected. On top of that, the research and methods used by people who care for
UX include tools and guidelines on conducting interviews and measuring the UX.
Those tools and methods can be used in both qualitative and quantitative testing.
To put it differently, UX is a sum of all the experiences, and this thesis primarily focuses on the user experience. 


\subsection{A/B testing}

According to \textcite{youngImprovingLibraryUser2014}, A/B testing is a comparative technique used to compare two versions of an experience.
The method can be used for both qualitative and quantitative testing.
In the commercial space, it's often used to measure desired features by exposing a portion of users to a version and another set of people to a different variant and analysing the differences. 
For example, when a company is trying to decide which button colour to use for the sign-up action, the first half of users might see a red sign-up button and the other half a grey one. The conversion rate for the users is measured in both cases, effectively signalling which choice performs better. 


The same method can be used by exposing people to two versions in sequence and conducting interviews with them with the goal of understanding the differences between them.
In the context of this thesis, this type of comparative analysis is important because it allows us to distil complex experiences with many features into something that can be compared. That ability proves useful in measuring difficult-to-observe features such as immersion.

\subsection{Immersion}

As regarded by \textcite{cambridgedictionaryImmersion2026} Immersion is the feeling and action of being completely involved in something. In an immersed state, the person is so deeply engaged with the medium that they forget about the outside world. This trance-like feeling can occur when interacting with many different artwork types, such as movies, video games or books. 
In the context of creating video games, immersion is often one of the most important qualities, since engaging with the virtual world on a deeper level makes for games that feel more real and enjoyable. 


Immersion as it is is not a binary state. It exists as a spectrum. Things can be more or less immersive, corresponding to many factors that create the experience. For example, a movie played without sound is going to be less immersive than the same movie with sound on.
Despite the broad definition, immersion is something that can be measured both qualitatively and quantitatively. In the case of qualitative measuring, it's often measured via interviews. When measured quantitatively, features such as eye coordination, breathing patterns, pulse, and brain function activity and other biomarkers offer some perspective on the degree of immersion. 


Since immersion is something that exists on a scale and can be measured, it's possible to isolate the individual features that deepen \& weaken its degree via measures such as A/B testing. Game designers often rely on certain features that deepen it. Commonly engaging multiple senses, such as hearing and touch, proves to work. 
On top of that, using realistic visuals makes for an easier entrance into an immersive state, and above all, a smooth, lag-free experience. A game that freezes and is unresponsive is a sure-fire way to break the immersion of its player.


For this thesis, immersion is the core of the focus. When done right it's something that seems to be natural for the end-user, while it's not just a mere byproduct of the artwork - instead, it's a handcrafted part of the experience. That ingredient is what makes it possible to transform pixels moving on the screen into an experience that makes people believe that they're somewhere else.
This term comes into play in this thesis during the discussion of the world that's portrayed by the video game accompanying this thesis.

\subsection{Input and game modality}

In the context of HCI, according to \textcite{fakhreddinekarraymiladalemzadehjamilabousalehandmonoursarabHumanComputerInteractionOverview2008} modality refers to all the different modes or channels in which communication, interaction, 
and experiences are relayed between the user and the computer. 

As a concept, it comes from linguistics and human-computer interaction.
But it can be broken into a few main dimensions, such as input or social modalities. In the context of this thesis, input modality is the main focus. 
The input modalities are all of the ways that the game communicates with the player. Different modalities correspond to different senses that can be engaged, such as visual, audio or haptic cues. 
This term plays a role in this thesis by allowing to label different input methods in a way that allows for a clear distinction and gives them a universally recognised name. 



\subsection{Voice navigation and natural language processing}

As noted by \textcite{interactiondesignfoundationWhatAreVoice2025} Voice User Interfaces allow people to control computers and other devices through speech recognition.
The response from the VUI can be anything, ranging from audio response to visual or haptic feedback.
It can be portrayed as an alternative interaction method to Visual User Interfaces, which rely on interacting by means of using visual modality. 
This type of emergent user interface is something that this thesis focuses on by creating a video game that employs voice communication. 


As noted by \textcite{holdsworthWhatNLPNatural2024} Natural Language Processing is an area of AI that allows computers to understand, interpret and parse human language.
Human communication is complex, filled with emotions and subtext. NLP focuses on translating that into machine-understandable language. 
This allows for natural language to be interpreted by the computer. This technology is what allows for Voice User Interfaces to exist, as they rely on the underlying human language.


Given that this thesis deals with voice input as its main focus, it's important to establish one crucial difference in that matter. In the realm of video games, there are many which allow some degree of control using the audio modality, 
in the means of issuing direct commands.


For example, by saying "Forward", the fan recognises that the player wants to 
move the character ahead just like pressing the right character on the keyboard would.
However, if the player were to say, "I would like to move my character to the direction in front of him", the game would not 
be able to recognise that, since that command is not something that it expects. 
Contrasting to that a game that can handle natural language input would be able to process such a request by extracting the 
wish of the player from the spoken phrase.
This kind of processing is what this thesis focuses on, compared to implementing just a list of commands that the player has to commit to his memory.

\section{Voice input in Video Games}

Voice as an input modality is used by many games in varying ways. 
Below are the main ways that it's been adapted to video games:

\begin{itemize}
    \item Communication support -- For many multiplayer experiences, instead of a primary input, voice is used to communicate with other players. This allows players to coordinate and is often required, such as in \textcite{offworldSquad2020}.

    \item Augmenting gameplay -- Sometimes voice is used as an augmentative input tool. In such cases voice is used to provide an additional layer of interaction with the game allowing for a richer experience.
    One such example would be \textcite{interactiveAlienIsolation2014}. In this horror game, any noises made by the player in real life would alert the enemy about the player's location. 

    \item Alternative input -- In certain cases, the game can be fully controlled by voice. \textcite{ubisoftshanghaiTomClancysEndWar2008} is a strategy game that allows the player to command his army by using either a voice or keyboard. 

    \item Partial input -- Some games offer a hybrid input model, requiring both keyboard and voice input. For instance, in a game \textcite{maisonbapYAPYAP2026} players are forced to cast magic spells by using their voice while navigating using the keyboard.

    \item Sole input method -- There are games that use voice as the only input method. A good example of that is \textcite{sonycomputerentertainmentjapanLifeline2003}, in which the player is forced to navigate through a space station using only his voice. 

\end{itemize}

\section{Gaps and Opportunities}

As discussed, existing games use pre-defined commands.
This type of voice input differs from how people naturally use spoken language. Those input systems don't understand context, subtext and can't process natural language in a way that a human could. On top of that, they require the player to remember keywords that are needed to interact with the system. 





% To illustrate, let's assume that a player needs to use the word "fire" to use their gun in-game. If they say "shoot" or "I want to use my gun", the game won't be able to understand their command.


With the rise of Deep Learning, NLP can be used as a tool that could potentially address those shortcomings. A system in which the player can express their commands in natural language has the potential to feel more reliable compared to existing voice control. 

The choice for this natural input method allows for two theoretical benefits. 
Firstly, it could perhaps make the participants feel more in control of the experience. Secondly, the cognitive load could be potentially reduced by not needing the player to remember the voice commands.
