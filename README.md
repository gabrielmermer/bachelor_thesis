# Bachelor Thesis Repository

This repository contains all materials related to the bachelor thesis project, including source code, design documentation, testing materials, submission artifacts, and the final written thesis.

## Repository Structure

```text
/
├── artifacts/
│   └── Submission PDFs and final deliverable artifacts
│
├── development/
│   └── Source code and technical implementation
│
├── gdd/
│   └── Game Design Document and design-related materials
│
├── testing/
│   └── Testing documentation, evaluation materials, and transcripts
│
└── writing/
    └── Main bachelor thesis document and related writing assets
```

## Folder Overview

### artifacts/

Contains final submission materials and generated deliverables, including:
- thesis PDF export
- testing report cards
- thesis concept document
---

### development/

Contains all software development files related to the project, including:
- frontend implementation
- backend APIs
- prototypes

Additional setup instructions for the software are available in the README file inside this directory.

---

### gdd/

Contains the Game Design Document (GDD), gameplay concepts, interaction flow descriptions, and supporting design materials used during development.

---

### testing/

Contains:
- usability testing documentation
- participant transcripts
- evaluation materials
- experiment notes

---

### writing/

Contains the written bachelor thesis document, references, figures, and supporting academic writing materials.

## Thesis Context

This project explores the feasibility and usability of voice-controlled interaction systems in video games using speech recognition, LLM orchestration, and tool-calling approaches.

The repository reflects both the research process and the technical implementation developed during the thesis work.
